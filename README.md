# Minecraft-Irl-Jukebox
> This project was inspired by [itismedld](https://github.com/itismedld), but all code and cad is original.

This is a 3D printed jukebox that plays music discs when inserted by using an RC522 and NFC tags embedded in the back of the discs. The whole jukebox is also powered by an ESP32-S3 Arduino microcontroller. The music files for the discs are stored on a microSD card connected to the wiring. Included below is a materials list for this jukebox, and you can find a demo video [here]().
